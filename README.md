## 💀 Rules of the Grind

```diff

+ Optimize when there's a reason to
+ Write clean Java
+ Test edge cases
+ Revisit problems I couldn't solve

- Blindly copy solutions
- Memorize code without understanding
- Skip complexity analysis
- Give up after one wrong approach
```
